# AWARE Engine (Context & Proactive Opportunities)

## Context Synthesis
The AWARE engine continuously collates:
- **Device Health**: Battery percentage, charging status, network availability.
- **Cognitive Posture**: User activity, focus state, active mission countdowns.
- **Resource Constraints**: Power saving flags, memory limits.

## Opportunity Pipeline
```text
System Context + Active Missions + UIC Attributes
                   │
                   ▼
       [AWARE Pattern Detectors]
                   │
                   ▼
     Opportunity Generated (Risk Scored)
                   │
                   ▼
    Zero-Trust Gate (Consent Evaluation)
                   │
                   ▼
    UI Proposal Display / Owner Verification
```
Opportunities provide explainable evidence (`reason` and `evidence`) before recommending actions.
