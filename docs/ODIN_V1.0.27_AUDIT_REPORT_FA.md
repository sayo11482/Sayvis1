## 3️⃣ تست معامله با حساب دمو (7 تست)

- **ساخت حساب:** لاگین deterministic، سرور `Vittaverse-Demo`، بالانس 10,000$، اهرم 1:100، تاریخ شمسی+میلادی
- **باز کردن BUY EURUSD:** ورود روی ask (price+spread/2) - اسپرد واقعی - مارجین 100$ - SL/TP اتومات (ریسک 0.5% - RR 1:2)
- **TP خورد:** سود واقعی محاسبه → **کمیسیون اتومات 20% به خزانه سوینکس** → خالص کاربر + بستن با تاریخ شمسی/میلادی
- **SL خورد:** ضرر ثبت شد → **کمیسیون صفر روی ضرر**
- **گیت توکن:** TV80 (پلاتینیوم) بدون استیک 2000 ODN → **مسدود شد - اجباری بودن تایید**
- **اکوییتی/مارجین:** equity = balance + floating - freeMargin ≤ equity - همه منطقی
- **خزانه صاحب نرم‌افزار:** پر شدن اتومات + ODN سوزانده شده (دیفلوشنری)

**صفحه دمو اپ:** قیمت واقعی ویتاورس هر 5 ثانیه → mark-to-market زنده + بستن اتومات روی SL/TP + دکمه بستن دستی + آمار وین‌ریت + تاریخچه با ستون کمیسیون.
